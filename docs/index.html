⚡ 3. Schéma de Câblage de l'Ensemble

Attention : Ne jamais alimenter les servomoteurs et les LED directement par la broche 5V/3.3V de l'ESP32. Utilisez toujours une alimentation externe 5V dédiée. Reliez impérativement toutes les masses (GND) ensemble.

Détail des connexions :

  • Alimentation 5V (Positif) → Bornier V+ de la PCA9685, entrée VCC du lecteur audio et fil 5V / VCC du ruban LED.
  • Alimentation 5V (Négatif / GND) → Bornier GND de la PCA9685, GND de l'ESP32, lecteur audio et fil GND des LED (Masse commune).
  • ESP32 (Pin 22 / SDA) → Broche SDA de la carte PCA9685.
  • ESP32 (Pin 21 / SCL) → Broche SCL de la carte PCA9685.
  • ESP32 et Lecteur Audio (UART - Croisement obligatoire) → Le TX de l'ESP32 va sur le RX du lecteur audio DY-SV17F, et le RX de l'ESP32 va sur le TX du lecteur audio (les signaux doivent être croisés).
  • ESP32 (Pin Data LED, ex: Pin 4) → Entrée de données du ruban WS2812B (DIN), conseillé avec une résistance de 330Ω/470Ω.
Composant Source Broche / Fil Composant Cible Rôle
Alimentation 5V Positif (+) PCA9685 (V+) / Audio / LED (5V) Puissance globale 5V
Alimentation 5V Négatif (-) Tous les GND (ESP32, PCA, Audio, LED) Référence de masse commune
ESP32 Pin 22 (SDA) / Pin 21 (SCL) PCA9685 (SDA / SCL) Pilote I2C pour les servos
ESP32 TX (Transmission) DY-SV17F (RX - Réception) Envoi des commandes audio (croisé)
ESP32 RX (Réception) DY-SV17F (TX - Transmission) Réception des retours audio (croisé)
ESP32 Pin Données (ex: GPIO 4) Ruban WS2812B (DIN) Signal des effets lumineux LED

Astuce de flashage (Mode Boot) : Si la connexion bloque ou si le message "Connecting..." tourne en boucle, maintenez appuyé physiquement le bouton BOOT de votre carte ESP32, cliquez sur le bouton d'installation, sélectionnez votre port série, et relâchez le bouton BOOT dès que la barre de progression du téléchargement commence.

📖 5. Premiers pas et Utilisation

  1. Débranchez et rebranchez l'ESP32 après le flashage.
  2. Sur votre téléphone ou PC, connectez-vous au réseau Wi-Fi : Robot-Config (Mot de passe : 12345678).
  3. Ouvrez votre navigateur sur l'adresse : http://192.168.4.1
  4. Allez dans l'onglet Wi-Fi pour basculer le robot sur votre réseau domestique.
  5. Contrôlez et créez vos scènes via l'interface web dédiée !
